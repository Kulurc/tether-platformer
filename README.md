# Tether - [Platformer Assessment]

A couple navigates their relationship together. As their relationship lengthens, they find themselves growing codependent on one another, making reaching their goal more and more difficult. A two-character platformer about a relationship, tied together by a tether. Made in Godot 4.5.1.

**Play in the browser:** [https://kulurc.github.io/tether-platformer/](https://kulurc.github.io/tether-platformer/) (keyboard and mouse)

| Input | Keys |
|---|---|
| Move / jump | A, D / Space |
| Switch character | Tab |
| Hook a ring | E |
| Reel in / Slack out | Left mouse / right mouse |
